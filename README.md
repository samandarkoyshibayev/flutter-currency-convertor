Currency Converter — Flutter Financial App
A high-precision financial utility application built with Flutter, offering real-time exchange rates and historical data visualization. This project demonstrates advanced data handling, functional programming patterns, and a clean, data-driven user interface.

Tech Stack & Architecture
This project implements a modular Clean Architecture to maintain a strict separation between business logic and the UI.

State Management: flutter_bloc (BLoC) with equatable for efficient, reactive state transitions.

Networking: Dio with talker_dio_logger for robust API communication and detailed debugging.

Functional Programming: Dartz for functional error handling using the Either type pattern.

Dependency Injection: GetIt for efficient service location and decoupled modules.

Data Visualization: fl_chart for rendering dynamic historical currency trends.

Internationalization: Intl for accurate currency formatting and multi-locale support.

Key Features
Real-Time Conversions: Instant exchange rate updates via REST API integration with Dio.

Historical Trends: Interactive line charts powered by fl_chart to visualize currency fluctuations over time.

Functional Error Handling: Uses the Either pattern to handle API failures gracefully, ensuring a crash-free experience.

Advanced UI/UX:

Custom typography using the Inter font family for a modern fintech aesthetic.

Detailed network logging for transparent data flow monitoring.

Optimized asset management for custom vector icons and branding.

Clean Dependency Flow: Centralized service management using a service locator for better testability.
